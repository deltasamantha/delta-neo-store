## P1
Study the current Gucci website as a visual
  referance for this ecommerce application. Analyze it's typography,
  spacing, layout, navigation, product presentation, imagery,
  buttons, borders, colors and responsive behaviour without copping
  it's text, assets or branding.
 Then Implement those principles in out project by setting up the
  global design system, including:
  - typography
  - color tokens
  - spacing
  - containers
  - buttons
  - links
  - borders
  - reusable responsive premitives
  in the appropriate tailwind and css files.
  Briefly explain the rules you implemented and the files you
  changed.
